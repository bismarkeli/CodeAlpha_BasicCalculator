# MegaCalculate 🚀

A modern, sleek, and fully responsive web-based calculator built using **HTML5**, **CSS3 (Grid & Flexbox)**, and **Vanilla JavaScript**. MegaCalculate features a classic dual-screen display, comprehensive arithmetic operations, full keyboard support, and a polished user interface.

---

## ✨ Features

- **Dual-Display Screen:** View your full expression history at the top while your active inputs or final results are displayed clearly at the bottom.
- **Full Arithmetic Suite:** Supports addition (`+`), subtraction (`-`), multiplication (`×`), division (`÷`), and percentage calculations (`%`).
- **Memory & Clear Controls:** 
  - `AC` (All Clear): Resets the entire calculator state.
  - `C` (Delete): Deletes the last entered digit.
- **Keyboard Support:** Full compatibility with physical keyboards for quick, seamless calculation.
- **Responsive Design:** Optimized to scale and look great across both desktop screens and mobile devices.
- **Custom Branding & Favicon:** Styled with custom visuals and a matching icon identity.

---

## 🛠️ Tech Stack

- **HTML5:** Semantic structure for the calculator keypad and screen.
- **CSS3:** Advanced styling using **CSS Grid** for the layout and **Flexbox** for the dual-display alignment.
- **JavaScript (ES6+):** Application state management, event handling, math logic, and keyboard listeners.
